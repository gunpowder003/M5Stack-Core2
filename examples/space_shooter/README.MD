This is a classic space shooter game for M5Stack Core2 written by ChatGPT with some code correction by me. 
To install: 
1. Ensure CORE2 is running with UIFlow 1.0 firmware. Burn it with M5Burner if it run with other firmware version
2. Open space_shooter.py via notepad and copy the code to browser/dekstop UIFlow 1.0 python view
3. Run the code
4. Start playing!
5. Controls:
   Left button (A) is to move spaceship to the left<br/>
   Center button (B) to restart once game is over<br/>
   Right button (C) to move spaceship to the right<br/>
