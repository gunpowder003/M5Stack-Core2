Dodge the block!

Objective is to avoid the block by tilting the device. Game is over if user touch the red blocks

Parameter that can be changed to increase game difficulty

# Player settings
PLAYER_SIZE = 20

SPEED_MULTIPLIER = 25  # Faster movement

player_y = SCREEN_HEIGHT - 30  # Fixed player position (bottom of screen)

# Block settings
BLOCK_WIDTH = 20

BLOCK_HEIGHT = 20

MAX_BLOCKS = 30  # Max difficulty level

BLOCK_SPEED_INCREASE = 0.7  # Blocks get faster over time
